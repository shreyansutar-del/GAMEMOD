# GAMEMOD
I started this project with CAD on Onshape. I included mounting points for M3 screws so it would be easier to take apart and put together.<img width="1049" height="647" alt="Screenshot 2026-10-03 at 3 20 08 PM" src="https://github.com/user-attachments/assets/e02956fb-6032-4bb4-a957-05a6d09941b0" />
After that, I put together the top part with the mounting points for the joystick and buttons. I added chamfers to make the product cleaner and not blocky-looking.
<img width="1470" height="956" alt="Screenshot 2026-10-03 at 12 14 24 PM" src="https://github.com/user-attachments/assets/e78857ae-edb1-4007-83d6-36aa6532a373" />
I decided to use a Raspberry Pico as it is pretty cheap and already has a GP2040 library for emulating game controller.One thing I really like about the GP2040 is the user-friendly Web Config.With the Web Config, you can easily assign buttons with needing to code the Pico.I added a hole to connect the Pico with a cable and screws to position a half-size breadboard in place. I might use a PCB later but a breadboard is great for prototypes.
<img width="1470" height="956" alt="Screenshot 2026-10-03 at 3 27 19 PM" src="https://github.com/user-attachments/assets/71b909c8-506b-4cf3-9a06-f975bc0a18c4" />


After completing the case, I wanted to create a Nintendo stand.This is because the Pico connects from the bottom of the console and the built in stand doesn't work.The only choice would be to put the Nintendo flat on the ground that would result in an uncomfortable position.I created a simple stand the requires supports and has a hole on the bottom to lead the cable through.
